# docs

Storybook (React + Vite) for developing and reviewing components from `@pawks/components`. See the [repo root README](../../README.md) for common commands and how to add a new component's story.

```sh
pnpm --filter docs dev              # start Storybook at http://localhost:6006
pnpm --filter docs build-storybook  # build the static site to storybook-static/
```
